What is a watermark?

A hidden pattern in the AI's word choices. This lab adds that pattern while generating text, then checks whether it can find it again.

It checks for this particular pattern. It cannot tell whether any random passage was written by AI.

How to read these results

Signal score (z-score): how far the pattern is above what we'd expect by chance. Higher means more evidence. It is not a percentage or a probability that AI wrote the passage.

Favored choices: the share of checked tokens on the green list. The list changes at each position using the previous token and your key.

Checked tokens: the token pairs counted as evidence. The first token, special tokens, and repeated pairs are excluded.

The cutoff is an experimental setting. Detection can be wrong; a result below the cutoff does not prove a watermark is absent.

How the hidden pattern works

Before each token is chosen, the key and previous token determine a “green list” of favored choices. Watermarked generation makes those choices more likely. The detector rebuilds the same lists and checks whether the passage uses them unusually often.

This research prototype uses HMAC-SHA256 and PCG64. Its approximate p-values and default detection cutoff have not been calibrated to guarantee a particular false-positive rate.
